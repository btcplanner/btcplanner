# BTC Planner 🇨🇦

Canada's Bitcoin planning hub — buy, store, and stack BTC the smart way.
Live at [btcplanner.ca](https://btcplanner.ca)

## Features
- Live BTC price (CAD/USD) via CoinGecko
- Fear & Greed index
- DCA calculator
- Sats converter
- AI Bitcoin guide chatbot
- Canadian affiliate directory
- Bitcoin 101 + CRA tax basics

## Run locally
```bash
npm install
npm run dev
```

## Build for production
```bash
npm run build
```

## Tech
- React 18 + Vite
- CoinGecko API (free)
- alternative.me Fear & Greed API (free)
- Anthropic API (chatbot)
